# framer-futurefocus-translator

One JavaScript file, `translator.js`, that translates the futurefocus.club site, which is built in Framer.

## What the script does

- The site text is in Russian. The script holds a built-in dictionary and swaps Russian text for English or Ukrainian.
- Locales: `ru` (default), `en`, `ua`.
- It picks the language from the `?lang=` URL parameter first, then from a saved choice in the browser (`ff_lang`), then from the browser language. Ukrainian and English browsers get their language, everything else gets Russian.
- It adds a small language switcher with one button per locale, and keeps the translation up to date as the page changes.
- The file header says where it goes: Framer, Site Settings, Custom Code, End of body.
- The file is generated by a separate translation pipeline. The commit message of each update says so. Do not edit it by hand, the next generated version will overwrite your change.

## Do not rename or move this file

The live site loads the script from this repository by URL, for example:

`https://raw.githubusercontent.com/nikitazhylkin/framer-futurefocus-translator/main/translator.js`

If the file is renamed, moved or deleted, the translation on the live site stops working. Update the content in place and keep the same name and path.
